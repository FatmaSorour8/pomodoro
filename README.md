# FocusFlow - Vanilla Pomodoro Timer

Professional Pomodoro Timer built with HTML, CSS, and Vanilla JavaScript.

## Features
- Custom focus/break/long break settings
- Session types: Study, Work, Reading, Coding
- Light/Dark mode
- Notifications and sound alerts
- Daily statistics and weekly chart
- Achievements and streak tracking
- Fully responsive modern UI

## Run
Open `index.html` directly in your browser.
